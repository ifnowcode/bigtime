# BigTime

[https://ifnowcode.github.io/bigtime](https://ifnowcode.github.io/bigtime)

I wanted to be able to turn any monitor into a large digital clock. Then I added local images in the background and transparency so the clock overlay the pictures. The result was a very big beautiful digital clock with rotating images. 

Now I'm using an random image API to fetch the images since local images won't work for public use. This will rotate the images every minute if check box is selected or you can deselect and manually refresh for a new image. This way you can leave an image you like in the background. This is currently using [https://picsum.photos/1920/1080?random](https://picsum.photos/1920/1080?random) for image generation from [https://picsum.photos/](https://picsum.photos/) which are intended for Ipsum Lorem use so some of the images aren't the most picturesque. If I find a better public random image API I'll update this.
